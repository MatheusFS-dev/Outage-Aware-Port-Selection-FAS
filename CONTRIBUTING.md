# Contributing

> [!IMPORTANT]
> Preserve study protocols and distinguish new experiments from the dissertation's retained results. Do not submit channel datasets, credentials, intermediate checkpoints, or generated logs. Retain third-party notices.

1. Fork the repository.
2. Create a branch for one focused change.
3. Update the relevant chapter documentation and run the checks described in the root README. Commit the change with a descriptive message.
4. Push your branch to your fork.
5. Open a pull request explaining the change and its verification.

Keep original reported results intact. Add new results separately with their configuration and provenance. Code contributions use Apache 2.0 and original prose and figure contributions use CC BY 4.0, subject to third-party exceptions.
